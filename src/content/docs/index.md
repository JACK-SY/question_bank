## 板块导航

## 使用说明

1. 每章一页，题目按难度标注：**★ 基础 / ★★ 进阶 / ★★★ 高频难题**
2. 答案与解析直接附在题目下方——先自己思考，再看答案
3. 侧栏顶部**搜索框**支持按章节标题关键字过滤
4. 题目持续补充中：新增章节时，在 `astro.config.mjs` 的 `sidebar` 中加一行，并在 `src/content/docs/banks/` 下新建章节文件即可
